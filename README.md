### 👨‍💻 เกี่ยวกับผม

ผู้เชี่ยวชาญโครงสร้างพื้นฐานไอที · ผู้ดูแลระบบเครือข่ายและเซิร์ฟเวอร์ · Full-Stack Developer

เชี่ยวชาญการดูแลระบบเครือข่าย **Cisco**, **Windows Server** และ **Linux** พร้อมพัฒนาระบบสารสนเทศแบบ Full-Stack ที่ตอบโจทย์งานจริงขององค์กร — ตั้งแต่ส่วนติดต่อผู้ใช้ ระบบหลังบ้าน ฐานข้อมูล ไปจนถึงอุปกรณ์ IoT นอกจากนี้ยังมีพื้นฐานด้านอิเล็กทรอนิกส์อุตสาหกรรม และประสบการณ์ระดับหัวหน้างานในภาคอุตสาหกรรม
