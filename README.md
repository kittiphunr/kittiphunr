# สวัสดีครับ 👋 ผม กิตติพันธ์ รัตนคร (Kittiphun Ruttanakorn)

นักวิชาการคอมพิวเตอร์ มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย วิทยาเขตแพร่  
พัฒนาเครื่องมือดิจิทัลเพื่อช่วยงานบริหาร งานพัสดุ และงานวิชาการของมหาวิทยาลัย

## 🛠️ ผลงาน

| โครงการ | รายละเอียด | ภาษา |
|---|---|---|
| **Formsmith** | เครื่องมือลากวางสร้างเว็บฟอร์ม ส่งออกเป็น ZIP หรืออัปโหลดขึ้นเซิร์ฟเวอร์ (FTP/FTPS/SFTP) ได้ทันที — รวม Form App Script Generator (ฟอร์มบน Google Apps Script) ไว้ด้วย | JavaScript |
| **BDA-MCU-PHRAE** | หอพุทธศิลป์ · ทัวร์เสมือนจริง 360° แบบ Street View | JavaScript |
| **Tor-Gen-Gov** | ระบบร่าง TOR และใบเสนอราคา — จ้างเหมาบริการบุคคลธรรมดา | JavaScript |
| **Form-Student** | แบบฟอร์มข้อมูลนักศึกษา (Google Sheets) รองรับ 3 ภาษา ไทย / English / 中文 | JavaScript |
| **[ID-PHOTO-MCU-STD](https://github.com/kittiphunr/ID-PHOTO-MCU-STD)** | ระบบจัดทำรูปถ่ายติดบัตรนิสิตตามรูปแบบของมหาวิทยาลัย | JavaScript |
| **Precision-QC** | ระบบตรวจสอบคุณภาพ | JavaScript / Python |
| **[IV-Monitor-BCNPH](https://github.com/kittiphunr/IV-Monitor-BCNPH)** | ระบบติดตามสารน้ำทางหลอดเลือด (IoT) | C++ |
| **BOQ-MCU** | เครื่องมือจัดทำ BOQ / ประมาณราคา | Python |
| **TOR-MCU-Standard** | ชุดเครื่องมือจัดทำเอกสาร TOR มาตรฐาน มจร. | VBA |
| **MCUPR-CANTEEN** | ระบบโรงอาหาร มจร. แพร่ | C++ |
| **Music-Player-ESP32-S3** | เครื่องเล่นเพลงแบบ Cover Flow บนจอ 2.8" ESP32-S3 | C |
